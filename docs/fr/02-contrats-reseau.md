# Contrats réseau

Le paquet network-contracts contient les contrats réellement utilisés par le réseau Streamr. Ils portent la logique on-chain tandis que les packages voisins facilitent l’accès depuis des applications Ethereum. Une intégration doit identifier la version du contrat, la chaîne visée et les autorités avant toute transaction.
