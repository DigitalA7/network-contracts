# Périmètre du monorepo

Le dépôt Streamr regroupe les contrats réseau, les interfaces TypeChain, des scripts, des sous-graphes et un paquet de configuration. Cette structure réunit le code de déploiement, les artefacts d’intégration et les adresses par chaîne. Le parcours distingue ces rôles pour éviter de confondre une ABI avec le contrat lui-même.
