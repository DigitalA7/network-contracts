# Sous-graphes et adresses

Les sous-graphes indexent les données de nombreux contrats du réseau et le paquet config rassemble les adresses déployées sur plusieurs chaînes. L’indexation est une vue dérivée : elle peut avoir un retard ou une couverture différente de la chaîne. Les adresses doivent être sélectionnées par réseau et version.
